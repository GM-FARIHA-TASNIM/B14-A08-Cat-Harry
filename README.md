# StudioSpace

**Peer-to-Peer Creative Workspace & Production Studio Sharing Platform**

StudioSpace is a platform where creative professionals can discover, share, and book production studios and creative workspaces.

## Live Website
https://b14-a08-cat-harry.vercel.app/

## Features
- User authentication and registration
- Browse available creative studios
- View studio details
- Add and manage studio listings
- Book available studios
- Protected routes for authenticated users

## Technology Stack
- Next.js
- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Better Auth

## Installation

1. Clone the repository.
2. Navigate to the client directory.
3. Install dependencies using `npm install`.
4. Configure the required environment variables.
5. Run `npm run dev`.

## Environment Variables
Configure the required environment variables before running the project. Never commit secret keys or database credentials.
